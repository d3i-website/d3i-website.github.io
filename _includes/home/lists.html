{% comment %} The front page's two lists: Latest news and Upcoming events. Copied from the
of docs/front-page-reference/index.html. Styles: _sass/_home-content.scss. News: the four newest items of site.news dated no later than the build. _config.yml has future: true, so a future-dated item is published and must be left out here. Events: an event's end is end_date, or date when end_date is missing or "" (the CMS writes a cleared optional field as '', which Liquid treats as true; every optional field is tested against "" too). Upcoming events (end on or after the build date) are rendered soonest first, up to eight, the fifth onwards hidden; the four most recent past events are rendered in a group that is hidden unless nothing is upcoming. assets/js/home-events.js redoes the split with the reader's own date, since builds can be weeks apart. Without JavaScript the built state stands. A row's link goes to external_url when it is filled in (in a new tab), else to the item's own page. The title is the link; its ::after covers the row, so the whole row is the link. {% endcomment %} {%- assign now_epoch = site.time | date: "%s" | plus: 0 -%} {%- assign today = site.time | date: "%Y-%m-%d" -%} {%- assign this_year = site.time | date: "%Y" -%} {%- assign home_news = "" | split: "" -%} {%- assign sorted_news = site.news | sort: "date" | reverse -%} {%- for item in sorted_news -%} {%- assign item_epoch = item.date | date: "%s" | plus: 0 -%} {%- if item_epoch <= now_epoch -%} {%- assign home_news = home_news | push: item -%} {%- if home_news.size == 4 -%}{%- break -%}{%- endif -%} {%- endif -%} {%- endfor -%} {%- assign upcoming_events = "" | split: "" -%} {%- assign past_events = "" | split: "" -%} {%- assign sorted_events = site.events | sort: "date" -%} {%- for item in sorted_events -%} {%- if item.end_date and item.end_date != "" -%}{%- assign item_end = item.end_date -%}{%- else -%}{%- assign item_end = item.date -%}{%- endif -%} {%- assign item_end_str = item_end | date: "%Y-%m-%d" -%} {%- if item_end_str >= today -%} {%- assign upcoming_events = upcoming_events | push: item -%} {%- else -%} {%- assign past_events = past_events | push: item -%} {%- endif -%} {%- endfor -%} {%- assign past_events = past_events | reverse -%} {%- capture more_disc -%} {%- endcapture -%}
