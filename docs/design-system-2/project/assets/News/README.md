# News

Pictures of the site's news items, for NewsCard's preview. In the artifact each is an upload, and its id is in `design-system.json` under `assetGroups` and on the artifact's asset cards. In a clone of the repository, the files are here, under `project/assets/News/`. Each is a copy of an `image` front-matter field in `_news/`, scaled to 1200px wide at most.

- `export-study-crate-card.webp`: "Ready to reproduce: export your data donation study". This is a real social-sharing card, 1200 × 630, the 1.91:1 shape every item's `image` is meant to have. The site's file is `assets/images/news/export-study-crate-card.webp` (2048 × 1075).
- `data-donation-symposium.webp`: "D3I and TDCC RIGHTS at the Data Donation Symposium 2026 in Berlin", a group photo, 16:9.
- `lennert.webp`: "Meet Lennert", a square portrait.
- `workshop-recap.webp`: "Workshop Recap: Towards Shared Standards for Data Donation Research", a room photo, 4:3.
- `erik.webp`: "Welcome our new research engineer, Erik van Haeringen", a tall portrait.

Only the first is a share card. The others show what the cards' 1.91:1 crop does to the pictures the site has now.
