# Projects

Pictures of completed studies, for ProjectCard's preview. They are placeholders until the first publish: `design-system.json` records each with a placeholder id (the MD5 of the file, flagged `"placeholder": true`), not an upload, so they show only once a copy has uploaded them (`tools/install_copy.py`). Each is a copy of an `image` field in `_data/completed-projects.yml`, scaled to 1000px wide. They are wide banner illustrations; ProjectCard shows each at its own shape, uncropped.

- `harmony.webp`: "HARMONY: Holistic Assessment of Mental Health and Online Youth", 2.6:1, by Vecteezy.
- `instagram-federated-learning.webp`: "Instagram, political preferences, and federated learning", 5.2:1, by Freepik.
- `netflix.webp`: "Behind the screens: Exploring Netflix via Data Donations", 4.5:1, by Vecteezy.

The completed-projects page credits Freepik and Vecteezy in its closing line.
