# Screens

Stills of the apps the site frames, for previews that must not call the live app.

- `script-selector.png`: the script selector's first step ("Select a platform"), 910 × 1100, as it ran at the reading column's width in November 2026. ScriptSelector's preview passes it as `still`, so the card shows the app without an iframe to the SURF Research Cloud workspace. Refresh it when the selector's look changes.

In the artifact it is an upload, and its id is in `design-system.json` under `assetGroups` and on the artifact's asset cards. In a clone of the repository, the file is here, under `project/assets/Screens/`.
