A quiet notice inside the reading column: a service status, a prerequisite. It has no frame and no tint. The notice sits on a short `blue` line from a `coral` node to a ring node, the front page's line and nodes in small.

Use it for a notice the reader needs before the content, not for emphasis. The Postit is for timely news, the blockquote for quoted words.

## What you provide

- One short paragraph, as children.

There are no pictures to pass.

## The values it draws

- `.callout` is `small` in `heading`, 28px in from the line, `space-24` below.
- `.callout::before` is the line: `line-page` in `blue`, down the left edge from the coral node to the ring node, as long as the text is tall.
- `.callout__node` is a `coral` `node-edge` (11px) at the top of the line, level with the first line of text.
- `.callout__ring` is a `node-ring` (8.4px) ring at the bottom: `surface` filled, a 1.4px `blue` edge.
