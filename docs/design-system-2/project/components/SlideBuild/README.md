One step of a build: several slides that share a title and a slide number, each adding one row to the same frame, so the audience sees one idea at a time while the earlier ones stay in view, dimmed. A line with a node per step across the top shows which step this is.

Mount `D3I.SlideBuild` in a design canvas; for a Slides deck, `D3I.slideMarkup(D3I.SlideBuild, props)` returns the slide as one `<section>` with inline hex styles to paste. Its props are in `components/index.d.ts` and on its card; the values below are what it draws, for anyone writing a slide by hand.

Pass `heading`, `eyebrow`, `steps` (the rail's names), `columns` (`left` for the plain column, `right` for the column being argued for), every `rows` entry (`label`, `left` and `right`, each a `title` and optional `text`; `tone: "coral"` for a row that makes a different kind of point) and, per slide, `shown`: how many rows that step shows. Give every step the same `number`.

- Every step has the same geometry: the same gaps and paddings, so a new row appears and nothing else moves. The title block, the step line and the table are 32px apart.
- The table is a grid of a 240px label column and two equal columns, 24px apart. 240px holds a two-word label ("NOT ASKABLE", 229px) on one line.
- Earlier rows carry `opacity: 0.35`; the newest is in full colour. Each row has 12px above and below its cells and a 2px `border` hairline between rows; the header row has 12px below it and the same rule.
- Budget: the last step must end inside the 816px flow, above the footer. The preview's four rows end at 812px; that holds for four rows when about half the cells have a two-line title or a second line, not all of them. Split a longer build over two slides rather than letting the last step run into the footer.
- Headers are `slide-eyebrow`: the plain column in `text-muted`, the argued-for column in `blue`. Row labels are `slide-eyebrow` in `text-muted`; a coral row's label has a 14px `coral` disc 12px to its left, hanging in the margin so the label keeps the column's width: the row's one spot of colour.
- Cells: a Nunito Sans 800 line at 28px over a `slide-small` line in `text-muted`, 8px apart. The argued-for cell has no fill: a 3px `blue` rule on its left marks it, as the step line is drawn, with padding 8px 24px; the plain cell has padding 8px 0, and the label 8px above it, so the three tops align. Corners are square and nothing is tinted.
- The title block: the eyebrow in `text-muted` caps, the title in the serif (Libre Caslon Condensed, provisional) at 420, 64px.
- The step line: The line is an inline `<svg>` 1664px wide (the width between the margins), with one node at the centre of each part's column (1664 / the number of parts), 3px `blue`, straight, from the first node to the last. Passed steps are 22px `blue` discs, the current step a 30px `coral` disc, steps ahead 20px `surface` discs in a 3px `blue` ring. Labels ("2 · Timing") 12px under the line, centred, Nunito Sans 700 at 24px: passed in `heading`, current in `heading` at 800, ahead in `text-muted`.
