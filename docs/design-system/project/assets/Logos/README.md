# Logos

The project's own mark and the organisations named in the footer sentence "A service provided by ODISSEI and supported by Eyra".

- `d3i-mark.svg` — the D3I mark: four rounded columns in `#4272ef`, `#ff5e5e`, `#ffcf60` and `#222222` with white counters, on a 49×48 box. The site uses it as the favicon only; there is no wordmark, the brand name is set in type (`label` at weight 800). The white fills are literal, so place it on a light ground or a brand fill, not on a dark theme surface without a backing shape.
- `eyra.png` — Eyra, 300px wide. Footer, at 6.1rem max width.
- `odissei.png` — ODISSEI. Footer, at 6.7rem max width.
- `pdi-ssh.png` — PDI-SSH, the funder named in the site README. Not placed on any current page.
