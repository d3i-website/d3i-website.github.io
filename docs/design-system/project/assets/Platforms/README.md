# Platforms

Logos of the platforms whose data has been donated in Port studies, shown as 18px icons inside platform pills on the impact page (`.usage-plat`). Third-party marks: use them only to name the platform, at icon size, beside its name. On slides they appear at 32 to 48px: on a SlideFrame card about that platform, or in a SlideStats tile of platforms studied.
