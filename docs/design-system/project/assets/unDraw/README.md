# unDraw

A selection of 36 from the site's library of 326 unDraw illustrations, each recoloured in one brand accent (the suffix says which: `_blue` = `blue`, `_coral` = `coral`, `_yellow` = `yellow`). Twelve per accent, chosen for the site's subjects: data, research, consent and agreement, privacy, community, events, newsletters, questions. The rest of the library lives in the repository under `assets/images/undraw/`.

Pick the accent that the surrounding component already uses (a blue routes rail, a coral step, a yellow movement card), one illustration per section, and place it as `Illustrations/README.md` says. Blue is the default when nothing nearby decides it.
